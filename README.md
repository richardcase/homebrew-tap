# homebrew-tap

Richard Case's personal Homebrew tap.

## Installing

Add the tap:

```sh
brew tap richardcase/tap
```

Then install any of the casks below with `brew install --cask <name>`.

## Available casks

| Cask | Description | Install |
| --- | --- | --- |
| [clowder](Casks/clowder.rb) | Cross-platform agent-orchestrator terminal | `brew install --cask clowder` |
| [jumux](Casks/jumux.rb) | Work on multiple features in parallel with coding agents. | `brew install --cask jumux` |
| [skillsctl](Casks/skillsctl.rb) | Install, update and remove agent skills. | `brew install --cask skillsctl` |

> **Note:** `clowder` requires macOS Sonoma or later.
